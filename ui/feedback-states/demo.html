Feedback States

基于 ui/feedback-states 的操作反馈演示，用于体验状态与时机。样式仅为示意；接入真实项目时请用当前 UI 组件库（Message、Skeleton、Empty、Dialog 等）与设计规范适配，勿直接复制本页皮肤。右下角为示意用 Toast 宿主。

1. Button busy 2. Skeleton 3. Optimistic 4. Toast 5. Empty 6. Error+retry 7. Inline 8. Progress 9. Confirm 10. Banner 11. Undo

1. Button busy

idle → pending → success | error

点击提交：最短 busy ~350ms；成功短驻后复位。连点不会重复触发。

状态：idle

2. Skeleton / loading

延迟 180ms 出骨架

点「加载列表」：先延迟再骨架，再出数据。点「瞬间返回」验证不会闪骨架。

3. Optimistic update

先改 UI，失败回滚 + Toast

点星星立即切换。第 2 项会模拟失败并回滚。

4. Toast / Snackbar

成功短、错误久、可带动作

弹出不同类型 Toast；删除带「撤销」。同时最多保留 3 条。

5 & 6. Empty / Error + retry

内容槽四态互斥

同一列表槽：骨架 / 数据 / 空 / 错误 互斥切换。

7. Inline result

字段旁即时结果

失焦或点保存：校验失败行内报错；成功显示「已保存」后淡出。

8. Long-running progress

阶段文案 + 可取消

导出约数秒；可中途取消。完成后 Toast。

变体：滑块拉满确认

10. Page banner

持久告警 · 不自动消失

切换级别；关闭后仅本会话隐藏。这是系统态，不是一次性 Toast。

下方为页面内容。Banner 持续占位，直到关闭或根因恢复。

11. Undo window

先改 UI · 倒计时内撤销 · 到期再提交

点删除：行先消失并出现 Undo 条；倒计时内可撤销。到期后才「真正删除」。
