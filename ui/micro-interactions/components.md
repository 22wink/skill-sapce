# Micro Interactions — Components

组件用「结构 + 状态 + 动效」描述，框架无关。规格原文见 `SKILL.md` 清单，本节展开实现契约。

---

## 1. Overlap stack（重叠排列）

**规格：** 做一个重叠排列组件，元素互相压住三分之一，末尾显示剩余数量，点击后依次散开并显示名称，再次点击收回。

### 结构

```
collapsed:
  [A][B][C][+N]          ← 可见叠层 + 剩余数徽章
expanded:
  [A  NameA] [B  NameB] [C  NameC] [D  NameD] …
```

- 叠层轴：默认水平（头像/卡片条）；垂直变体可选，规则相同
- 重叠量：后项相对前项偏移 = **可见宽度 × 2/3**（即压住 **1/3**）
- 默认可见张数：`maxVisible`（建议 3–4）；超出以 `+N` 显示，`N = total - maxVisible`
- 每项：缩略图 / 色块 / 图标；**expanded 时必须显示名称**

### 状态

| State | 行为 |
|-------|------|
| `collapsed` | 叠压 + 末尾 `+N`（若 N>0） |
| `expanding` | 按序 stagger 展开，名称随项淡入 |
| `expanded` | 全项铺开，间距均匀，名称可见；`+N` 隐藏 |
| `collapsing` | 逆序或同步收回叠压 |

整组点击切换；单项点击在 `expanded` 时可另作选择（可选，默认整组 toggle）。

### 动效

- 展开：`translateX`（或 Y）+ `z-index` 重排；stagger `40–70ms`
- 名称：`opacity 0→1`，可与位移同段或略晚 `40ms`
- 收回：`220–280ms`，叠回原 overlap

### 实现要点

- 用绝对定位或负 `margin` 做 overlap；展开用 `gap` / 明确 `offset`
- `+N` 是真实节点，不是伪元素凑合（便于点击与读屏）
- `prefers-reduced-motion`：取消 stagger，一次到位

## 2. Fill progress（底色填充进度）

**规格：** 用组件背景的填充宽度表示完成进度，勾选一项时填充平滑前推，完成时整个组件轻微提亮。

### 结构

```
┌─ surface ─────────────────────────────────┐
│ ▓▓▓▓▓▓▓▓░░░░  ← fill 层宽度 = progress%   │
│  ☐ Step 1                                 │
│  ☑ Step 2                                 │
│  ☐ Step 3                                 │
└───────────────────────────────────────────┘
```

- **进度载体是组件背景填充宽度**，不是单独的细 progress bar（可另加文字百分比，但不替代填充）
- 底层：`--surface`；填充层：`--accent` / 品牌色，`opacity 0.15–0.35`（保证文字可读）
- 列表项：checkbox + label；勾选驱动 `completedCount / total`

### 状态

| State | 行为 |
|-------|------|
| `idle` | `width = (done/total)*100%` |
| `advancing` | 勾选后 fill **平滑前推**（勿瞬跳） |
| `complete` | `done === total`；整卡 **轻微提亮**（brightness / 浅叠加光 / 边框微亮） |

取消勾选时 fill 平滑回退；从 complete 回到未完成时撤销提亮。

### 动效

- fill：`width` 或 `scaleX`（`transform-origin: left`），`280–400ms` ease-in-out
- 提亮：`200ms`；幅度克制（感知到即可）

### 实现要点

- 填充层 `pointer-events: none`，位于内容之下
- 进度公式只认勾选项，不混入外部假进度
- 完成时除提亮外可保留勾选态，避免只靠颜色

## 3. H-accordion（横向手风琴）

**规格：** 做一个横向手风琴组件。默认等宽窄条，点击某条展开变宽显示详细，其余同步收窄，内容延迟淡入。

### 结构

```
collapsed（等宽）:
  [ 1 ][ 2 ][ 3 ][ 4 ]

one expanded:
  [ 1 ][ ==== 2 detail ==== ][ 3 ][ 4 ]
         ↑ 宽条；其余同步变窄
```

- 默认：所有条 **等宽**；窄条只显示标题 / 序号 / 图标
- 展开条：变宽，显示详细（文案、元数据、操作）
- **其余条同步收窄**（总宽度守恒：容器 100%）
- 同时仅一条 `expanded`（手风琴）；再点当前条可收回全部等宽（推荐）

### 状态

| State | 行为 |
|-------|------|
| `allEqual` | 均分宽度 |
| `expanding(i)` | i 变宽，其他变窄；细节区先占位 |
| `expanded(i)` | 宽度稳定；**内容延迟淡入** |
| `collapsing` | 回到等宽；内容先淡出再收宽度 |

### 动效

- 宽度：`flex-grow` / `fr` 动画，`250–320ms`
- 内容：`opacity`，在宽度完成后再延迟 **`80–120ms`** 淡入（规格：延迟淡入）
- 收窄条：隐藏细节，仅留标题，防抖闪

### 实现要点

- `flex` + 动画 `flex-grow`，或 CSS `grid` 列宽；避免每帧量文字撑开导致抖动
- 窄条文字可 `writing-mode: vertical-rl`（可选）或省略号
- 键盘：方向键切条，Enter 展开

## 4. Under tray（组件托盘）

**规格：** 在组件下方垫一层深灰（或者较组件背景淡一点的颜色）托盘，默认只露一行，点击时托盘向下展开显示明细，主组件位置保持不动。

### 结构

```
┌──────── main card（位置固定）────────┐
│  标题 / 摘要 / 主操作                  │
└────────────────────────────────────┘
╔════════ tray（在下方垫着）══════════╗
║  默认一行摘要                         ║
║  （展开后）明细行…                    ║
╚════════════════════════════════════╝
```

- 托盘色：深灰，或 **比主组件背景略淡/略深一档**（对比弱于主卡，像「垫层」）
- 层级：托盘在主卡 **下方**（可略向左右伸出 0–8px，或同宽）；主卡可轻微遮住托盘顶边，强化「垫着」
- **主组件位置保持不动**：展开只增加托盘高度向下长，不 push 主卡、不整体平移主卡

### 状态

| State | 行为 |
|-------|------|
| `peek` | 托盘只露 **一行** |
| `opening` | 托盘高度向下动画 |
| `open` | 显示明细列表 / 字段 |
| `closing` | 回到一行 |

点击：主卡或托盘行均可作为 toggle（二选一，需一致）。

### 动效

- `height` / `grid-template-rows: 0fr→1fr`，`220–300ms`
- 主卡：`transform` 不因展开而改变；可保留自身 hover，但勿联动下移

### 实现要点

- 布局用「主卡 + 托盘」列堆叠；动画托盘，不动画主卡 `top`
- 明细过多时托盘内部滚动，避免一次撑满屏
- 读屏：`aria-expanded` 挂在控制节点上

## 5. Magnify dock（跟手放大图标排）

**规格：** 做一排跟随手指放大的图标，按距离手指远近平滑缩放，相邻图标同步让位，松手选中当前图标。

### 结构

```
        👆 finger / pointer
[ a ][ b ][ C ][ d ][ e ]
         ↑ 最近最大；邻项中等；远端最小
```

- 一排图标（建议 5–7 个）；基准尺寸 `base`，最大 `base * 1.6–2.0`
- 缩放 = **距触点的平滑函数**（高斯 / 余弦衰减），非硬切两档
- **相邻同步让位**：放大项占位变宽，左右项 `translate` 让出空隙，避免重叠
- **松手**：选中当前最近点图标，settle 回基准缩放并高亮选中态

### 状态

| State | 行为 |
|-------|------|
| `idle` | 等大；显示当前 `selected` |
| `tracking` | 跟手连续更新 scale + 位移 |
| `settling` | 松手动画到选中布局 |
| `selected` | 选中项有标记（底点 / 标签） |

### 动效

- 跟手：无 delay，rAF / pointermove 直接映射
- 影响半径：约 `2–3` 个图标宽
- 松手 settle：`180–240ms` ease-out

### 实现要点

- 用指针 X 与各图标中心距离算 scale；`scale` 同时驱动间距（让位）
- 触摸：`touch-action: none` 于 dock 区域，防页面滚动抢手势
- 鼠标离开行：平滑回 idle，不强制改选中
- 键盘：左右选择，Enter 确认（无跟手时的可达替代）

## 6. Pull summary（下拉展开摘要）

**规格：** 做一个可下拉展开的顶部摘要，收起时为一行胶囊，下拉时跟手展开成完整统计面板，下方内容下一并变暗。

### 结构

```
collapsed:
  (  摘要胶囊：关键指标 / 标题 / 小 chevron  )

pulling / expanded:
  ┌──────── 完整统计面板 ────────┐
  │  多指标 / 图表 / 筛选入口      │
  └─────────────────────────────┘
  ░░░░░ 下方页面内容变暗 ░░░░░
```

- 收起：**一行胶囊**（pill / capsule）
- 下拉：**跟手**改变面板高度 / 展开进度 `0→1`
- 展开完成后为完整统计面板；可再点收起或上推收回
- **下方内容一并变暗**：遮罩 `opacity` 跟随拉动进度（不是等到完全展开才突然变暗）

### 状态

| State | 行为 |
|-------|------|
| `collapsed` | 胶囊；遮罩 0 |
| `pulling` | 高度跟手；遮罩跟手；内容未完全可交互 |
| `expanded` | 面板完整；遮罩稳定（如 0.35–0.5）；面板内可交互 |
| `collapsing` | 跟手或动画收回 |

### 动效

- 跟手：`translateY` / height 直接映射 finger delta，可加轻微橡胶阻尼（超拉）
- 松手：超过阈值（如 40–50% 高）→ 展开，否则回弹胶囊
- 遮罩与面板同一进度函数

### 实现要点

- 面板 `position` 与页面流：建议 sticky/top 固定，下方内容不被动诡异跳动；变暗用 fixed/absolute 遮罩层
- 遮罩点击：默认收起面板
- 与下拉刷新冲突时：仅在胶囊手柄区启动手势，或水平意图优先滚动
- `prefers-reduced-motion`：点击胶囊直接展开/收起，跳过跟手

## 跨组件共享约定

| Topic | Rule |
|-------|------|
| 圆角 | 胶囊 / dock 用全圆或大圆角；卡与托盘 `16–24` |
| 时序 | 可打断；以最新手势为准 |
| 数据 | 名称、进度项、明细、图标、统计均为 props，不写死文案 |
| 皮肤 | 可与 `soft-card-ui` token 混用，但不依赖其物流语义 |
| 测试 | 每组件至少覆盖：初始态、一次完整交互、快速连点/取消 |
